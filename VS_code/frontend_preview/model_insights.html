Why Logistic Regression?

The final model was selected based on the evaluation results obtained during development.

📈 Classification Performance

Logistic Regression produced the strongest evaluation results among the tested models on the cleaned development holdout.

⚡ Efficient Prediction

Its lightweight structure makes it suitable for fast prediction in an interactive symptom-analysis application.

🔍 Interpretable Approach

The model provides a relatively transparent classification approach compared with more complex ensemble architectures.

🧩 Easy Deployment

The trained model can be serialized and integrated into the Streamlit prediction workflow using a compact model package.
